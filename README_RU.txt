ЭКЗАМЕН МВД 2026 — приложение для Android

В базе: 2 раздела, 20 билетов в каждом разделе, 400 вопросов.
Правильные ответы перенесены из выделенных курсивом вариантов исходных Word-файлов.
Иллюстрации к вопросам, присутствовавшие в документе по огневой подготовке, также добавлены.

ВОЗМОЖНОСТИ
- отдельные разделы «Служебная подготовка» и «Огневая подготовка»;
- выбор любого билета;
- случайный тест на 20 вопросов;
- режим повторения ошибок;
- подсветка выбранного и правильного ответа;
- сохранение статистики и ошибок на устройстве.

КАК УСТАНОВИТЬ НА ANDROID ЧЕРЕЗ ANDROID STUDIO
1. Распакуйте архив на компьютер.
2. Откройте папку AndroidProject в Android Studio (Open).
3. Дождитесь синхронизации Gradle. При необходимости установите Android SDK Platform 35.
4. Подключите телефон с включенной отладкой по USB или выберите эмулятор.
5. Нажмите Run. Для APK выберите Build → Build Bundle(s) / APK(s) → Build APK(s).

БЕЗ ANDROID STUDIO
Папка с index.html, app.js, style.css, questions.json и images — веб-версия приложения.
Для установки как PWA ее нужно разместить на HTTPS-хостинге и открыть адрес в Chrome на Android,
затем выбрать меню браузера → «Установить приложение» / «Добавить на главный экран».

ПРИМЕЧАНИЕ
Варианты ответов сохранены в формулировках исходных файлов. В двух вопросах огневой подготовки
и одном вопросе служебной подготовки в исходном документе представлены только три варианта;
приложение не добавляет отсутствующие варианты.
