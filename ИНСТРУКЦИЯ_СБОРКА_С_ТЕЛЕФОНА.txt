КАК ПОЛУЧИТЬ APK БЕЗ КОМПЬЮТЕРА (через GitHub Actions)

Нужен аккаунт GitHub. Сборка происходит на серверах GitHub, телефон нужен только для загрузки проекта и скачивания APK.

1. Откройте https://github.com и войдите или создайте бесплатный аккаунт.
2. Распакуйте архив проекта на телефоне (приложение «Файлы» обычно умеет распаковывать ZIP).
3. В браузере откройте https://github.com/new
   Название репозитория: mvd-exam-2026
   Выберите Public (так проще использовать бесплатные GitHub Actions для личного проекта), затем Create repository.
4. В созданном репозитории выберите Add file → Upload files.
5. Загрузите ВСЁ содержимое папки android_exam_app, включая скрытую папку .github. Важно: в корне репозитория должны быть папки .github и AndroidProject, а также index.html, app.js, style.css и questions.json.
   Если файловый выбор Android не показывает скрытые файлы, включите в файловом менеджере «Показывать скрытые файлы».
6. Нажмите Commit changes.
7. Откройте вкладку Actions в репозитории. Дождитесь завершения workflow «Build Android APK» (зелёная галочка).
8. Откройте завершённый запуск workflow, прокрутите до Artifacts и скачайте Ekzamen-MVD-2026-APK.
9. Распакуйте скачанный ZIP. Внутри будет app-debug.apk. Нажмите на него и установите. Если Android спросит разрешение, разрешите установку неизвестных приложений для браузера/файлового менеджера, которым открываете APK.

Если сборка завершится ошибкой, откройте запуск в Actions и пришлите скриншот красной ошибки — по нему можно будет исправить проект.

Примечание: это debug APK для личной установки, не публикационная подписанная версия Google Play. GitHub Actions использует облачную сборку; Android Studio на телефоне не нужна.
